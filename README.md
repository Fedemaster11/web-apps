### Framework
A framework is a predefined structure that helps developers build applications more efficiently. It provides tools, rules, and reusable components for software development.

Examples:
- Laravel
- Angular
- Django
- React Native

### Library
A library is a collection of reusable code that developers can use to perform specific tasks without writing everything from scratch.

Examples:
- React
- jQuery
- NumPy
- Bootstrap

### Package Management System
A package management system is a tool used to install, update, remove, and manage software dependencies required by a project.

Examples:
- Composer for PHP
- npm for JavaScript
- pip for Python

### Git
Git is a distributed version control system used to track changes in source code and allow developers to work on different versions of a project.

Important Git commands:
- `git clone` - Downloads a repository.
- `git status` - Shows the current status of the repository.
- `git branch` - Displays or manages branches.
- `git checkout` - Changes between branches.
- `git add` - Adds changes to the staging area.
- `git commit` - Saves changes locally.
- `git push` - Uploads commits to a remote repository.
- `git pull` - Downloads and integrates remote changes.
- `git merge` - Combines changes from different branches.

### GitHub
GitHub is an online platform used to store and collaborate on Git repositories.

A **Pull Request** is a request to review and integrate changes from one branch into another branch.

A **Merge** combines the changes from different branches into a single branch.
